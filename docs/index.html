CNN Pruning Benchmark — interactive visualisations

Supplementary interactive visualisations from my thesis on activation-based pruning for VGG-16 / CIFAR-10. Source code on GitHub.

  • VGG-16 architecture
    An interactive walk-through of the network adapted to CIFAR-10 — click any layer to learn what it does.
  • Pruning methods explained
    Short reference to the twelve activation-based pruning criteria implemented in the benchmark.
  • Pruning results
    Interactive results dashboard — accuracy, FLOPs, and recovery curves across all configurations.
  • Pruning explorer
    Per-filter explorer for individual conv layers across all methods and pruning ratios.
